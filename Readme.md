# Urban Pulse – Smart City Mobility Intelligence

Urban Pulse is a Power BI-based smart city mobility analytics project focused on Bengaluru.

## Project Overview

The project integrates multiple mobility-related datasets to provide insights into:

- Public Transit
- Ride-Hailing
- Bike Sharing & Micromobility
- Traffic & Road Safety
- Weather & Environment
- Demographics & Geospatial Analysis

## Key Features

- Interactive Power BI dashboards
- Mobility and traffic KPIs
- Geospatial and location-based analysis
- Ride-hailing demand analysis
- Transit and route analysis
- Traffic and road safety insights
- Weather and mobility analysis
- DAX-based analytical measures

## Tools Used

- Power BI
- Power Query
- DAX
- GitHub

## Dashboard Modules

- Geospatial Analytics
- Traffic & Road Safety
- Reliability Metrics
- Ride-Hailing Intelligence
- Mobility Equity
- Executive Analytics

## Project Structure

`/datasets` – Source/processed datasets  
`/powerbi` – Power BI dashboard files  
`/screenshots` – Dashboard previews  
`/documentation` – Project documentation

## Project Goal

To provide a unified analytical view of Bengaluru's mobility system and support data-driven urban mobility decisions.
